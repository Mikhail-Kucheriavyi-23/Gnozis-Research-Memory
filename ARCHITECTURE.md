# Gnozis Research Memory Architecture

Research-Memory is the private machine-readable research, evidence, provenance, architecture-history, and context-restoration repository.

## Domains
- mathematics
- physics
- history
- science
- engineering
- philosophy
- architecture
- audits

## Boundary
Research-Memory is not operational Core and is not the public runtime database. Selected, validated Knowledge Packages may be published to Gnozis under explicit policy and provenance.

## Context
Research-Memory preserves project context without making internal development memory part of the public product surface.
